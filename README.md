# 1С DevOps Studio

Десктоп-приложение (Electron) для повседневной работы с 1С-проектом: git-история и синхронизация, сборка/разбор `.cf`/`.cfe`/`.epf` и заливка конфигурации/расширения в базу через Конфигуратор.

## Возможности

**Git**
- Выбор репозитория (автоподхват `1C-AI_WORK_BASE` и `1C-claude-skills`) и ветки
- История коммитов с diff по файлам
- Рабочая копия: stage/unstage, коммит
- `fetch` / `pull` / `push`, индикатор ahead/behind

**1С (через `1cv8.exe` DESIGNER и `v8unpack`)**
- Разобрать: конфигурация БД → XML (`/DumpConfigToFiles`), распаковка `.cf/.cfe/.epf` (v8unpack)
- Собрать: выгрузка `.cf/.cfe` из БД (`/DumpCfg`), сборка из папки (v8unpack)
- Залить в Конфигуратор: `/LoadCfg`, `/LoadConfigFromFiles`, `/UpdateDBCfg` (с `-Extension` для расширений)
- Живая консоль с реальной командой и выводом

## Запуск (dev)

```bash
npm install     # ставит electron (бинарник ~90 МБ; при медленной сети — зеркало ELECTRON_MIRROR)
npm start
```

## Сборка .exe

```bash
npm run dist    # electron-builder, NSIS-инсталлятор под Windows
```

## Требования

- Node.js 18+
- Платформа 1С (`1cv8.exe`) — автоопределяется в `C:\Program Files\1cv8\<версия>\bin`
- Python + `pip install v8unpack` — для распаковки/сборки без платформы

## Настройки

Хранятся в `%APPDATA%/onec-devops-studio/settings.json`. Репозитории, базы (файловые/серверные), путь к Python — на вкладке «Настройки». Пароли баз хранятся локально в этом файле (в git не коммитится).

## Замечания по 1С

- Операции DESIGNER требуют монопольного доступа к базе — при открытом Конфигураторе будет ошибка блокировки.
- Результат каждой операции пишется во временный `/Out` лог и выводится в консоль приложения.
